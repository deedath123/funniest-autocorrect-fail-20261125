## The fail

> Dad, can I have $20 for the school strip tomorrow? The bus leaves at 7.

## What it does

`main.py` writes a single one-line autocorrect fail to `/output/entry.txt` — 71 characters, one line, UTF-8, no padding and no explanation after the punchline. It uses only the Python 3.13 standard library.

## How to run it

```bash
python3 main.py
cat /output/entry.txt
```

Set `MAKEFUN_OUTPUT_DIR` to write the entry somewhere else instead of `/output`.
